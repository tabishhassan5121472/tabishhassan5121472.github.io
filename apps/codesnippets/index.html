Save Any Code

Paste or type snippets in 20+ programming languages — Swift, Python, JavaScript, TypeScript, Go, Rust, Java, Kotlin, HTML, CSS, SQL, Bash, Ruby, PHP, C#, C++, Dart, YAML, JSON, Markdown, R, and Lua. Every snippet gets automatic syntax highlighting for keywords, strings, comments, and numbers.

Copy In One Tap

Need that snippet back? Tap once to copy it straight to your clipboard, with haptic confirmation and a "Copied!" toast. No digging through old files, no switching apps.

Organize Your Way

Group snippets into custom collections, add tags for quick filtering, star your favorites, and pin the ones you reach for most. Full-text search finds any snippet by title, code, description, or tag in an instant.

Built For Developers

  • Monospace code display with optional line numbers and word wrap

  • Share a snippet as text or export it as a file with the correct extension

  • Works great on iPhone and iPad

Privacy First

No account required. Every snippet is stored on your device — nothing is uploaded anywhere unless you choose to export it yourself.
